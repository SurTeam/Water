# 界面布局与交互

本文区分各前端共享的交互原则与 Go 桌面的具体布局。Go 桌面技术边界见 [Go GUI](desktop-gui.md)，终端网格见 [终端规范](terminal-rendering.md)，资源与响应性见 [性能规范](performance.md)。开发中的候选视觉方案按 [工作约定](../AGENTS.md#文档更新时机) 留在上下文，用户确认实现并要求 commit 后再更新当前规范。

## 布局与信息层级

桌面由左侧 connection/workspace/Agent 导航、自绘标题栏内 tabs、主区域 split terminal 和按需打开的 Settings/弹窗组成。标题栏、tab、侧栏和字体度量可配置，不能把某次默认尺寸当作固定设计常量。窗口与终端几何分别使用其正确的逻辑/物理坐标，网格余量按现有布局规则处理。

导航操作必须路由到所属 connection；多窗口各自保留选择。Agent 使用前台进程和可用 OSC 信息呈现状态，不能把进程存活猜成任务正在工作，不能把 Paused 猜成正在等待审批。Web/TUI 使用同一模型边界，但各自具有明确的布局与设置限制。

当前入口：`internal/goui/ebiten_layout.go`、`ebiten_sidebar.go`、`ebiten_window.go`；Web/TUI 分别见 [Web](browser-access.md)、[TUI](terminal-ui.md)。

## 视觉与弹窗规则

- 颜色与字号使用配置主题及字体度量，按钮和输入框按实际字体垂直居中；避免用含混的字段名称描述不同对象的颜色。
- 窗口内弹窗无投影，背景只压暗一次；叠加 Settings、更新或其他面板时不重复叠加遮罩。
- 模态交互应明确捕获底层输入，异步结果核验对象与面板生命周期；这是一项设计要求，当前滚轮拦截的缺口见下文。
- 保存、预览和丢弃具有明确语义。Go GUI Settings 使用草稿并在保存后保持打开；Web 的本站设置即时写入 localStorage，不套用同一草稿流程。
- macOS 自绘窗口控制按钮失焦时变灰，不显示悬停符号；真实 OS 焦点状态与测试注入输入保持区分。
- Workspace 普通点击不显示拖动提示，超过现有 5dp 阈值才开始拖动反馈。侧栏不提供逐行 workspace 关闭按钮，关闭走快捷键/菜单及确认路径。

## 选择与破坏性操作

拖选按字符格中线确定插入边界，正反向一致。Shift 点击保留锚点更新另一端，允许跨锚点；双击选词结果不能被松开位置覆盖。高亮、复制、光标与宽字符共享终端列宽语义。

关闭含任意 tab 的 workspace 必须确认，目标固定为打开确认时的 UUID，不能因当前选择变化而关闭另一个对象。空 workspace 可直接关闭。GUI、TUI、Web 保持这个行为边界；各端输入和设置能力依自身契约。

## 一致性与验收

桌面、TUI 与 Web 共享模型归属、操作目标和确认语义，各端布局适应其输入设备与屏幕限制。TUI 使用自身主题和窄屏导航，不能假设具备 GUI 的像素、原生窗口或设置能力。

每项可配置功能必须具有可发现的入口、清晰的对象名称和生效范围；验证同时覆盖控件可达、修改与持久化。视觉验证覆盖正常、失焦、弹窗叠加和最小可用布局，避免只验证默认截图。

视觉断言需要真实 Draw 截图与几何，交互断言检查相应模型/PTY/viewport 结果。设置覆盖必须同时验证控件、可达入口和保存往返。物理输入/IME 与真实设备行为不能由 control 注入测试替代，详见 [测试策略](testing.md)。

## 当前实现边界

`internal/goui/ebiten_input.go` 的 wheel 路径拦截更新、Settings 和 remote 面板，但未同样检查 workspace 关闭确认和 rename；这些弹窗仍可能让滚轮作用于底层。标题栏和窗口控制保持可用，关闭整个窗口不触发 Settings 面板的脏草稿确认。因此不能将“所有模态全面阻止一切底层输入”作为现有实现保证。
