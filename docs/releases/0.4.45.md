# 0.4.45

- 隔离单 pane 的阻塞输入、输出解析和控制路径；supervisor 输入、输出、resize/close 使用独立连接，输入与 resize 不再占用全局命令锁。
- 终端输出使用 WT4 原始二进制帧，输入协商使用 WT5，保留旧服务端兼容路径；队列有界，输入错误归属到 pane。
- PTY 部分写入超时继续发送未写后缀，避免延迟读取时丢失或重复粘贴及键盘序列。
- 接通 Kitty 键盘消歧、事件类型/释放和全部按键报告，保留传统功能键兼容编码。
- 新增阻塞输入下 GUI/邻接 pane/关闭验证及延迟读取的逐字节校验；完善粘贴、历史查询和设置定位测试。

在 macOS arm64 完成完整回归各项检查，失败的设置定位测试修复后单独重跑，并补齐 Metal 检查。控制 API 测试不代表物理键盘/IME 验证；Linux musl、Windows 和 macOS amd64 为交叉构建，不声称异平台原生运行覆盖。
