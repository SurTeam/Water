# Water 0.3.9

降低历史滚动 CPU 和重复分配，修复首次启动的终端像素尺寸报告，不新增限频或定时器。

- 历史滚动和选择自动滚动复用未变化的不可变快照行；终端拒绝鼠标上报时不再生成快照。
- 滚轮事件完整处理并立即唤醒画面，不再触发之后 120 ms 的持续空转；保留按键、拖拽和 IME 的持续输入路径。
- 原生菜单静态属性按配置变化刷新，动态 enabled 和窗口可见性仍每次检查；未变化的发布数据直接复用。
- 减少空白单元格排版和临时分配，Cell 从 72 缩至 64 字节。
- 修复首次布局未获得原生焦点时 CSI 14t/16t 像素尺寸回复过期的问题；共享 PTY 的行列尺寸仍由有焦点的窗口控制。

同机器、同样 120 次小步滚动的 8 秒普通原生 GUI 对照中，CPU 约 15.73% → 9.61%，下降约 39%。诊断对照的滚动累计采样分配量下降约 33%–61%，滚动位移和新行重绘数一致。这些是短窗口结果，不代表长期 CPU 均值或 RSS 同比下降。

全量 Go 测试、go vet、相关 race 检查通过；真实 GUI 滚动、原生菜单和现场快捷键修改、多窗口、8/16/32 pt 宽字符选择、换行、光标及 zsh 输入验证通过。完整证据、一次未复现的原生恢复超时及验证边界见[滚动优化报告](https://github.com/SurTeam/Water/blob/v0.3.9/docs/scrolling-optimization-2026-10-05.md)。

macOS arm64 安装包使用本地原生构建，并通过 signing-only workflow 签名和正式发布。
