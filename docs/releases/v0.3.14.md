# Water 0.3.14

修复 Coding Agent 图标尺寸、Pi 重绘历史和终端输入跟随，并提供可复用的测试策略。

- Agent 状态图标使用固定尺寸的矢量轮廓，避免字体造成大小不一致。
- 通用清屏策略保留进入应用前的终端历史，应用全量重绘只替换自己的历史。Pi 策略位于 Agent 层，欢迎词及 Ctrl+O 展开/收缩不再重复；覆盖延迟检测、attach replay、历史裁剪和 resize。
- 修复输入请求在 PTY 回显前被提前消耗的情况，键盘输入及 Enter 及时跟到终端底部。
- 新增 `water ctl ui content`：只读目标 GUI 客户端的当前视口或有界历史行，支持 window/pane 身份、sequence 和分页一致性检查，不改变滚动、选区或剪贴板。
- GUI 测试复用 `scripts/water_test.py`；`scripts/run-go-regression.py` 提供 unit/terminal/agent/full 分层入口、步骤超时和机器可读报告。Pi 测试使用本地工具输出会话，不调用模型，也不再拖选复制文本。
- 固化 [测试策略](../testing-strategy.md)，同步更新 AGENTS 与 water-control skill。macOS 开发机使用与 CI 相同的证书在本地签名，CI signing-only 保留为备用。

验证：`~/.venv/bin/python scripts/run-go-regression.py --profile full` 的 13 个步骤全部通过；本次 macOS 运行约 59 秒。包含全仓 Go 测试、vet、race、全部 scenario，以及真实 GUI 的 400 行只读分页、Pi Ctrl+O、状态图标像素、四种 Agent 启动、选区/图片历史和 PTY 查询。已签名 release 包也通过真实 GUI 内容检查、`codesign --verify --deep --strict`、证书匹配及 ZIP 完整性验证；本次没有触发签名 CI。
