# Water 0.4.3

终端新增 `CSI ? c`（RIS）完整复位序列；设置 → 服务 页面的 Web 服务入口移动到能力详情下方，按钮下方空间全部留给内容输出。

- 终端解析器新增 `CSI ? c` 处理（VT340+ RIS），与 `ESC c` 行为一致：清屏、属性/光标/DEC 私有模式复位、视口归零。`CSI Ps c`（DA1 设备属性查询）与 `CSI > Ps c`（DA2）不变。
- 新增 `TestCSIRISFullReset`、`TestCSIRISDoesNotAnswerDA`、`TestCSIRISMatchesESCRIS` 及 DA1/DA2 参数路径测试。
- 设置 → 服务：`Web 服务` 按钮现在紧跟能力详情列表（展开时）或标题行（未展开时），相关入口成组显示。
- 内联 Web 状态（启动/停止、Web 设置、设备、随 server 启动、配对二维码）只在独立 Web 服务弹窗内渲染，服务页按钮下方保持空出供内容输出。
- 新增 `TestWebServiceEntrySitsUnderCapabilityList` 锁定布局契约；`TestWebModalIsolatesSettingsAndEscapeReturns` 扩展验证能力详情展开/收起两种情况。
