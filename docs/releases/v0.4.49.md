# Water v0.4.49

## macOS 升级后新 shell 保留完全磁盘访问

原地替换 supervisor 二进制后，旧进程仍会接管已有 PTY，但 macOS 按现在该路径上的签名检查它，后续新开的 shell 会丢失应用已有的完全磁盘访问。

新 server 启动时比较 supervisor 进程的启动时间和当前二进制的修改时间。二进制已替换，或旧 supervisor 不能报告自身时，新 shell 改由当前二进制新启动的 supervisor 创建。升级前已经在跑的终端仍留在旧 supervisor，恢复时按原 pane id 接回。这些已有 shell 不会恢复权限。

## 验证与发布状态

`goplatform`、`gosupervisor`、`goserver` 和 `goterminal` 的 Go 测试通过。用当前已签名的 `water-pty` 新启动的 shell 可以读取 Downloads；升级前保留的旧 supervisor 不能。未重启用户正在运行的 Water。
