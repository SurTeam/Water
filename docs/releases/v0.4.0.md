# Water 0.4.0

新增 server 自有的 Web 终端接入：浏览器通过 HTTP/WS 或 HTTPS/WSS 直连所选 server，可在桌面端为本地和 SSH server 管理 Web 服务、扫码配对与设备授权。

- Settings → Server 的独立 Web 服务窗口提供启动／停止、配置、配对和设备撤销。停止 Web 不会结束已有 PTY。
- 默认监听 `127.0.0.1:8080`；地址和端口独立配置，可显式选择 `0.0.0.0`。随 server 启动 Web 的偏好独立保存。
- 配对二维码有效期为五分钟；已配对设备的授权跨 server 重启和 socket 变化保留。授权记录只保存凭据摘要，浏览器使用 cookie，管理操作不会向网页开放。
- 浏览器支持终端选择、分屏、回放与重连、系统字体设置、已保存 server 的直接切换，以及手机端辅助按键、键盘显示／隐藏和顶部控制区折叠。
- 相册二维码在本机 worker 中解码，不上传照片；多分辨率和平滑重试改善环境照片与屏幕拍摄纹理的识别。
- HTTPS 页面说明 PEM 证书链及匹配的未加密私钥要求。本地和 SSH server 的证书都从本机选择，应用时通过所选管理连接验证并导入 server 的私有目录。Web 操作按钮增加边框，应用按钮与 Settings 保存使用一致的主题样式。
- 修复其他客户端调整 PTY 列宽后，手机网页终端超出视口的问题；保留 replay 的尺寸处理，并在完成渲染后重新适配前台网页。

验证：0.4.0 完整 unit profile（go vet、全仓 Go 测试、race）通过。正式 macOS arm64 包的真实 GUI、本机和隔离 OpenSSH server 配对、文件选择／取消、证书导入、可信 CA 与主机名验证、终端输入／回放、字体及手机视口检查通过；额外驱动 160 列的外部 PTY resize 验证网页重新适配。测试清理自有 GUI/server/socket，并保留用户已有实例与配置。

macOS arm64 包在本机使用 SurTeam 发布证书签名，严格验证 updater/server/GUI/app 的签名、时间戳、版本、变体及 ZIP 完整性。四个 embedded server payload 按 0.4.0 / release 交叉编译；本次不提供未经原生验证的 Linux GUI 或 macOS Intel 安装包。物理手机上的 CA 信任、输入法与跨设备网络仍需在目标设备验证。

浏览器直连需要可达的 server 地址；SSH 配置别名不会自动成为 Web 地址，Water 不提供公网中继或 NAT 穿透。HTTPS 证书需要覆盖实际访问的 IP／域名，访问设备需要信任签发 CA。
