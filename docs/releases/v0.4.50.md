# Water v0.4.50

## TUI 大粘贴合流，输入背压不再拖垮前端

TUI 不再把 tcell 的小 EventQ 与第二层 `ChannelEvents` 直接叠在大粘贴路径上。屏幕泵先排空并合并 bracketed paste / 连续 KeyRune，再以分块 `SendInput` 写入；`ErrSessionBackpressure` 进入 pending 重试，而不是永久停输入或退出事件循环。GUI 将同类背压标成可重试状态；浏览器在输出等待缓冲超限时先给出明确错误再重连。

有界队列仍保留：隔离与背压是设计，不是崩溃条件。

## 验证与发布状态

`gotui`、`goclient`、`goterminal`、`goui` 的 Go 测试通过，含合流粘贴与 pending 输入相关用例。未跑完整 GUI regression profile；异平台产物仅交叉编译打包，不另做运行时验收。
