# Water 0.3.8

降低 GUI 常驻内存和连续输出时的重复分配，不降低刷新频率、字号、历史容量或画质。

- 静态字体轮廓使用只读文件映射，移除整表常驻 Go 堆副本，并按字体生命周期释放。已解码字形独立持有数据，保证字体回收后的安全性。
- 恢复字形绘制批处理：只有越过单元格边界的字形才使用独立裁剪；复用行排版和临时字形缓冲。
- 同配置短时测试中，空闲物理内存约 314 → 209 MiB，两轮输出后约 338 → 276 MiB。物理 footprint 与 RSS 口径不同，结果不代表数小时运行上限。
- 修正宽字符验证脚本对汉字的错误居中要求，改为检查换行前后字形像素一致；保留图标的居中和边距验证。

全量 Go 测试、相关 go vet、字体并发/race 检查通过；真实 GUI 语言、字号、窗口布局及字号 8、16、32 的宽字符、选择、光标、换行和 zsh 提示符验证通过。

macOS arm64 安装包通过本地原生构建和 signing-only workflow 发布。测量方法与验证边界见[修复报告](https://github.com/SurTeam/Water/blob/v0.3.8/docs/gui-memory-fix-2026-10-05.md)。
