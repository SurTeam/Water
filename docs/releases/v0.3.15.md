# Water 0.3.15

改进应用升级后与既有 Local/Remote server 的兼容性检测，新增 Server 设置页，并提供有保护的布局和当前目录恢复。

- GUI 和 server 双向检查协议、API 与必需能力。产品版本不同仍可复用兼容 server；server 依赖源码指纹变化时提示重启，缺少必需能力时进入诊断模式。
- Settings → Server 展示版本、server revision 与双向能力，提供刷新、保存布局、二次确认重启和重试恢复。
- 重启前查询各终端的实时目录，校验并持久保存恢复数据；恢复 workspace/tab/pane 身份与顺序、标题、分屏方向/比例和窗口选中项，再创建新 shell。运行中的任务和终端历史不会恢复。
- 多窗口、布局变化、保存失败或无恢复能力的旧 server 不会被自动关闭；替换或导入失败保留恢复文件。Local 替换程序在关闭旧 server 前校验，避免选中残留旧二进制。
- Remote 使用跨产品版本稳定的 endpoint，并保守发现旧版 endpoint，避免升级时新建空工作区。server/payload 构建统一注入实现指纹。
- 测试使用独立二进制、socket/config 和可辨识的 Water Test 窗口；关闭前验证实例/PID 归属，记录既有 Water 进程是否保持不变。新增真实临时 OpenSSH fixture，清理 sshd、master、测试 server 和私钥。

验证包括完整 unit profile（vet、全仓 Go 测试、race）、Local/Remote 原生 GUI 的备份/重启/实时目录恢复、真实 OpenSSH 的认证/默认 payload 部署/Unix 转发/断线重连，以及不同 GUI 产品版本复用同一 server。真实 SSH 服务位于独立本机进程，原生 Linux GUI 运行仍未验证。

正式 macOS arm64 release 包已在本机完成正式证书签名，并通过 nested/app strict verification、与已安装版本的 publisher requirement 匹配、ZIP 完整性检查，以及实际 release 包的 Local/真实 OpenSSH 恢复、断线重连和 server 复用测试。签名与测试均未触发 CI，未替换或重启用户已安装的 Water。

使用方法与旧版限制见 [Server compatibility and recovery](../server-compatibility.md)。
