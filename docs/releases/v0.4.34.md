# Water 0.4.34

修复 `clear` 后向上滚动仍能看到旧内容的问题。

- 正确处理先清除历史、再清屏的控制序列，避免清屏时将旧画面重新存入滚动历史；控制序列分块到达时行为一致。
- `Ctrl+L` 继续清屏并保留历史。清除后产生的新输出仍可通过后续 `Ctrl+L` 保留。
- 保持 TUI 备用屏幕退出后恢复主屏内容和光标位置的行为；备用屏幕输出不会使已清除的主屏历史重新出现。

沿用发布前已完成的 terminal profile 验证，覆盖 Go 单测、vet、race、GUI/PTY、真实 Pi 重绘及 TUI 重连滚轮。最后的主屏状态隔离调整另经相关单测、race、vet 和最终构建的真实 GUI 检查：`clear` 后客户端历史不再包含旧输出，随后 `Ctrl+L` 保留新输出。本次版本递增不重复运行整套测试。

发布 macOS arm64 安装包，使用本机 SurTeam 证书签名。
