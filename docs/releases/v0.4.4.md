# Water 0.4.4

macOS UI 测试窗口默认以未聚焦模式启动：窗口可见，但不抢占当前应用的焦点。普通 Water GUI 的启动行为不变。

- `WATER_TEST_UNFOCUSED=1` 让原生窗口以 `InitUnfocused` 启动。`show-window` 在该模式下只显示窗口，不激活应用。
- 未聚焦时 control API 的键盘输入仍然送入终端。共享 PTY 的行列尺寸仍只由真正获得焦点的窗口改变。
- 可见网格与共享 PTY 行列一致时，补发带 cell 像素的 resize，让 `TIOCGWINSZ` 的像素尺寸不再是 0×0。kitty `icat` 因此可以在未聚焦测试窗口里显示图片。
- 所有 `scripts/go-ui-*.py` 单独运行也会设置未聚焦模式。焦点专项断言改为检查窗口可见且未聚焦，不再要求启动后成为 key window。

验证：query、language-grid、lifecycle、graphics-history、hyperlink、tabs-colors、update、pi-redraw、settings、multiwindow、parity smoke 通过。wide-glyph 的反向半字符选择、background、cursor IME、系统通知权限和本机 Playwright 浏览器未在本次通过；detached-startup 与 real-ssh 未运行。
