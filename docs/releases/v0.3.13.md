# Water 0.3.13

改善 Coding Agent 状态显示、终端历史保留和系统通知。

- Agent 启动时即使发送 `CSI 3 J`，Water 仍保留已有 scrollback。
- Agent 侧栏使用一致的圆形图标区分运行、空闲/完成、暂停并需留意、错误和离线状态。
- macOS 系统通知区分 Agent 启动、完成、需要留意和错误；Settings 可启用通知并配置 Agent 与普通 Shell 命令的长时间运行阈值。
- 后台 Shell 提醒只在 Water 窗口和命令 pane 都未聚焦时发送；交互式 shell 不触发提醒。
- 修正 zsh Delete 键回归测试，使其显式验证 emacs 键图，并等待 PTY 退出后再清理测试目录。

验证：`go test -count=1 ./...`、`go vet ./...` 和真实 Ebitengine GUI control smoke 通过。
