# Water v0.4.42

## 设置外观与像素滚动

- Agent 设置以主题面板区分 profile 导航与编辑区，调整字段间距、标签对齐和主保存按钮；Web 服务使用状态卡、集中操作区和设备行，HTTP/TLS 配置保持清晰的标签与输入列。
- 普通 Settings、Agent 字段、Web 配置及已配对浏览器列表改用连续像素滚动，保留小数滚轮输入，避免小幅滚动被丢弃。内容溢出时显示比例滚动条，支持拖动滑块和点击轨道翻页，并按实际内容钳制边界。
- 字段绘制与命中区域按同一视口裁剪，固定操作区保持可达；键盘切换字段时按实际行高滚动到目标。配置归属、保存及 Web 服务操作语义保持原有约定。
