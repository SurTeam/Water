# Water 0.3.16

改进设置项的可发现性、弹窗显示和 macOS 窗口失焦时的控制按钮表现。

- 设置 → 主题中的“连接颜色”改为“主机卡片颜色”，明确区分主机卡片背景与活动主机卡片背景。
- 核对全部 178 个设置项；覆盖测试同时检查配置字段对应的控件、实际设置列表入口及保存/加载往返。
- 打开设置时调暗背景；从设置中打开更新页面不会重复调暗。
- 移除更新页面的弹窗阴影。
- 自绘窗口控制按钮在窗口失焦时变灰，恢复焦点后恢复彩色；失焦时不显示悬停符号。按钮仍使用现有自绘标题栏和控制路径。
- 新增真实 GUI 像素回归，覆盖主机背景设置入口、设置遮罩、叠加更新页面、更新页无阴影，以及 macOS 双窗口焦点切换，并纳入 GUI regression profiles。

验证：完整 unit profile（go vet、全仓 Go 测试、race）通过；真实 macOS GUI 验证通过。测试使用独立配置、socket 和自有进程，保留用户已有 Water 实例。正式 macOS arm64 包在本机使用发布证书签名，验证 nested/app strict signatures、ZIP 完整性和隔离 release GUI 行为。
