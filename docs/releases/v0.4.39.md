# Water v0.4.39

## 通知修复

- 普通终端 bell 不再生成“终端需要你的注意”通知，也不会被误标为 Agent 交互请求。
- 保留已识别 Agent 的 OSC 注意通知，匹配 Agent 的权限请求和 question 状态继续触发；其他 Agent 的状态报告不会误触发。
- 删除“Agent 仍在运行”通知，避免仅因持续运行而打扰用户。

## 验证与发布

针对性通知回归和完整 unit profile（测试框架检查、Go vet、全量 Go 测试、race 检查）通过。未对各平台系统通知的实际弹出效果作运行时验收。

发布资产覆盖 macOS、Windows、Linux 的 amd64/arm64。macOS 和 Windows 使用平台代码签名，并提供签名的 SHA256SUMS；交叉构建不等于原生桌面运行验证。签名不代表 Apple 公证、系统预装证书信任或 SmartScreen 信誉。Windows 应用内更新安装仍不支持。

上传后通过 GitHub API 提供的 SHA256 digest 和文件大小对照本地文件验证，不重新下载发布资产。
