# Water v0.4.48

## Agent 状态解析繁忙时保留上一次 OSC 状态

终端解析锁暂时拿不到时，不再把 Agent 状态当成缺失而显示 Unknown→Completed，也不会因此再次发出 Agent completed 通知。滚动等会与解析争用锁的路径复用上一次已解析的 OSC 状态。

## 窗口铺满后仍可拖动，换屏时收到当前屏幕高度

- macOS 双击标题栏铺满当前屏幕后，窗口处于 `isZoomed`。原先标题栏按下时直接放弃系统拖动，铺满后无法移动。现在铺满后仍走 `performWindowDragWithEvent:`。
- 侧栏空白区域与标题栏共用同一命中，本来就可以拖动和双击铺满；连接、workspace、Agent 等控件仍优先响应。这次修复同样覆盖侧栏空白区域。
- 窗口从较高的显示器移到较矮的屏幕时，按当前屏幕的可见区域收缩高度并只在垂直方向移回屏幕内。宽度和水平位置不变。全屏和最小化不处理。

## 验证与发布状态

高度适配的几何单元测试覆盖超出、偏上、偏下、已经合适以及屏幕尺寸未知的情况。真实双显示器拖动过程中的实时表现仍需人工确认。
