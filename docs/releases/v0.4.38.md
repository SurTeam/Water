# Water v0.4.38

本版本加入 Windows 原生 GUI/server 支持，并补齐本地多平台打包流程。

## Windows

- 通过 ConPTY 运行交互终端，支持分栏、resize、退出输出排空和 supervisor 重连；每个终端由独立 Job Object 管理，关闭时清理其后代进程。
- 默认采用 PowerShell；`pane.execute` 支持输出捕获、退出码、超时和取消。子执行继承导出的环境和当前目录，变更不会写回交互 shell。
- 支持 Windows 剪贴板、文件拖放、原生 PEM 文件选择器及平台快捷键。中文输入已由用户在 Windows 实机确认。
- 支持原生 SSH 认证、SFTP 部署和有界 stdio bridge，可用于 Windows 客户端或 Windows 远端；关闭连接不会终止远端 server。
- 修复 Windows 私有文件权限检查及恢复文件发布，确保 Web 授权、TLS 和受保护恢复能够正常工作。

## 本地构建与签名

- 新增 `scripts/build-go-windows.sh [all|amd64|arm64]`：在 macOS/Linux 上直接交叉编译 Windows GUI/server/updater 并生成 ZIP，无需 Windows 主机。包内包含 PTY supervisor、六目标 payload manifest 及依赖许可证。
- Windows shell 打包入口支持 Authenticode 签名、RFC3161 时间戳和签名验证；密码从受保护文件读取。
- macOS/Linux 打包按 `GOARCH` 选择目标架构，避免跨架构产物被标成宿主架构；macOS 使用本机 Apple SDK，Linux 使用本机容器中的目标编译器和系统库。
- 修复 Linux release 暂存目录与主程序重名导致的组包失败，补齐 Go 运行库及本地 fork 的许可证和修改说明。
- 嵌入的 headless server 覆盖 darwin/linux/windows × amd64/arm64，manifest 记录构建身份、大小与 SHA256。

## 验证及边界

Windows 原生回归覆盖 16 个包、323 个通过的测试／子测试；交互桌面验证包含首帧、PowerShell 往返、分栏/resize/关闭、保留 shell 状态的恢复、剪贴板复制/粘贴及原生文件选择器选择/取消。中文输入采用用户实机验收结果，与自动中文输出渲染检查分开记录。macOS 全量 unit、vet、race 回归已通过。

Windows arm64 完成构建验证，未在 arm64 Windows 设备运行。部分现有测试仍采用 Unix shell/path 假设，Windows 专用原生套件不等同于 Windows 全量 `go test ./...` 通过。Windows 应用内更新安装尚不支持，请下载 ZIP 解压使用。

macOS 包使用 SurTeam 本地代码签名；Windows 可执行文件使用同一签名证书进行 Authenticode 签名并加时间戳。`SHA256SUMS`、`SHA256SUMS.sig` 和公开签名证书用于验证全部发布归档，包括 Linux 包。签名不等同于 Apple 公证、系统预装的证书信任或 SmartScreen 信誉。
