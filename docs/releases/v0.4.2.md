# Water 0.4.2

拖拽或粘贴文件/文件夹到终端时，自动转换为 shell 引用的绝对路径字符串。

- 从 Finder 拖拽文件到终端窗口，路径以单引号包裹后插入命令行（如 `'/tmp/my file.txt'`）。
- 复制文件/文件夹后 Cmd+V 粘贴，同样转换为引用路径。
- 路径中的单引号用 `'\''` 转义，空格、中文等多字节字符安全处理。
- 多文件拖拽以空格分隔。
- 当前台程序启用了 bracketed paste 模式时（如 vim、bash 读取输入时），不做转换，原始内容直接传给程序自行处理。
- 图像粘贴（Ctrl+V 发送 0x16）不受影响。
- 非 macOS 平台保留接口，暂不实现文件拖拽。
