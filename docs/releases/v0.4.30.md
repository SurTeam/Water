# Water 0.4.30

修复特定 Workspace 新建 tab 或 split pane 时，shell 启动失败并留下“空窗格”的问题。

- macOS 查询终端当前目录时使用 UTF-8 locale，避免 C locale 将中文路径输出为显示转义，继而被误当成启动目录；查询结果必须是存在的绝对目录。
- 目录查询避免 `lsof` 的阻塞式文件系统探测，并将外部查询预算由 1 秒缩短至 250 毫秒，减少创建终端时的共享命令等待。该预算不代表整个 tab/split 创建操作的耗时上限。
- 新建 tab 或 split 的 shell 启动失败时撤销新对象，并恢复原 workspace、tab 和 pane 选择，避免遗留空窗格。

完整 unit profile（harness、vet、全量 Go 测试及相关包 race）通过。新增回归覆盖 C locale 下的中文和空格路径、父 shell 切换目录后的继承、查询失败时回退，以及创建失败后的布局与选择恢复。签名安装包在隔离 GUI 中通过中文目录下的真实新 tab、split 快捷键和 shell 命令验证，原有 Water 实例保持运行。

本次提供 macOS arm64 安装包，使用本机发布证书签名并通过 app 签名及 ZIP 校验。Linux 原生运行未验证；未执行完整 terminal profile。运行中的旧 server 不会因下载新版本自动加载修复，需通过应用提供的服务端升级恢复流程加载新 server。
