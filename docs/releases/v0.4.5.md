# Water 0.4.5

macOS 编辑按键与文件插入修复：转发 Delete 和长按编辑键现在跟随真实 key event 送达，Finder 拖放/粘贴在未聚焦窗口中也能插入绝对路径。

- 转发 Delete 键发送 `ESC [3~`，不再被当作 Backspace；Backspace 仍发送 DEL。
- 长按 Backspace、方向键等编辑键与字母键一样走 key-down repeat，不再重启 IME 会话，候选窗口仍按 points 显示。
- Finder 复制的文件会携带 TIFF 图标和 file-reference URL，之前粘贴会被吞成 Ctrl+V 或解析不到 POSIX 路径。现在优先读取 filename 列表，drop 也在未聚焦窗口的 Update 返回前送达。
- 新增 `TestMacVirtualKeySeparatesDeleteFromBackspace`、`TestTextCommandQueuePreservesBurstOrder` 等编辑键测试，以及 `filedrop_test.go` 中 Finder 粘贴与未聚焦 drop 的路径解析断言。

验证：`go test ./...` 全仓通过；`go vet ./...` 无告警。
