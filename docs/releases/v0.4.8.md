# Water 0.4.8

修复 GUI 启动时对繁忙 server socket 的误判，并隔离各终端的输出流，避免高频输出拖慢控制请求和其他终端。

- 已有 server 的握手暂时超时时，GUI 会在有界启动期限内重试。Unix socket 连接超时视为监听器繁忙，避免删除仍在使用的 socket 或错误启动替代 server。
- 每个终端使用独立、有界的输出队列，降低高频输出和 GUI 背压对控制请求、其他终端 attach 的影响，并保留输出顺序。
- 新增延迟握手、繁忙 socket、终端流隔离、真实 PTY 洪流和 TUI 恢复回归测试。
- 长时间运行的终端增加浮动提示，便于查看任务状态。
- 支持可配置的 Agent profiles 和自定义 Agent 识别，提供设置界面及 `water ctl` 管理入口。

验证：完整 `full` 回归通过，覆盖 `go vet`、全部 Go 单元测试、race、scenario 和真实 GUI 检查。性能测试采用 Go 包串行执行，避免并行负载影响吞吐比值；单独测得 server/direct 吞吐保留率为 85.6%。macOS 文件路径读取改用类型明确的 Objective-C 字符串调用，消除 `go vet` 的 unsafe.Pointer 告警。
