# Water 0.4.20

- 降低空闲窗口的调度唤醒，仅可见活动光标驱动闪烁重绘；失焦光标保持稳定显示。
- 修复 macOS Metal 截图读回后 drawable 引用失效引起的崩溃，隐藏窗口不再积累最终屏幕绘制命令。
- 修正窗口事件处理后的可见性判断，避免恢复窗口时使用旧状态跳过呈现。
- 改善缺少匹配 server 时的启动诊断，显示检查过的候选路径。
- GUI 回归共享桌面锁，保全全部剪贴板类型，严格验证自有进程清理；弹窗像素测试使用实际面板边界。
- 安装包补齐本地依赖许可证、NOTICE 和引擎修改说明。

验证：完整 full 回归通过，覆盖 Go 测试、vet、race、终端和 Agent GUI、两种原生 Metal 读回路径。后续可见性时序修正通过相关 Go、Metal、空闲与持续输出最小化恢复检查。空闲 CPU 的短时隔离对照从 1.78% 降至 1.06%，不代表持续负载或 macOS Energy Impact 的固定降幅。恢复查询仍约 0.67 秒；不含 Water/Metal 的原生 AppKit 对照同样出现事件循环阻塞，该系统转换等待未被消除。
