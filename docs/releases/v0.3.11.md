# Water 0.3.11

修复输出期间的历史选择、zsh 向后删除，并补齐常用终端图片显示和 coding agent 图片粘贴路径。

- 持续输出保留选区和历史位置；鼠标上报不会抢走历史选择，历史裁剪后选区仍对应原来的文本。
- zsh 缺少 Delete 绑定时自动补齐，保留已有自定义绑定，不修改用户启动文件。
- PTY 接收真实像素尺寸，`kitten icat` 可正常检测并显示图片；支持新版 kitten 的无填充 Base64 压缩流。
- Kitty 图片保留历史位置和高度，正常屏幕与 alternate screen 隔离，部分历史裁剪仍保留可见图片；清除屏幕图片不会误删历史，`--clear-all` 可清除全部图片。
- Unicode 占位符支持组合字符行列定位及完整 32 位图片 ID，滚动时裁剪原图，不重新缩放可见片段；修复冒号 RGB 和组合字符宽度造成的图片缺失、竖缝。
- Sixel 图片占用正确行数；iTerm2 inline 图片继续使用同一历史定位路径。
- macOS 图片剪贴板粘贴识别 PNG/TIFF 等原生格式，并交给 coding agent 读取；真实 Codex 和 Claude Code 界面已验证图片附件，无需粘贴图片字节或自动发送模型请求。

验证包括 Go 全套测试、go vet、scenario suite、真实 GUI 图像/选择/Delete/粘贴检查与截图。使用 `~/Pictures/20150803201548_uVt5k.jpeg` 验证普通和 Unicode `kitten icat` 模式，图片高度为 27 行，滚回历史后仍正确显示。

图像支持范围和测试命令见 [操作文档](../Documents.md#terminal-images-history-and-paste)。macOS arm64 安装包经过本地原生构建及 signing-only workflow 签名发布。
