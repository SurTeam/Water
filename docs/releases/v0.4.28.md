# Water 0.4.28

新增 Finder 文件夹右键服务 `Open New Workspace in Water`。

- 在 Finder 中选择文件夹，通过右键菜单的 Services 调用，创建新的本地 workspace，并在该文件夹目录启动终端。
- 多选文件夹时分别创建 workspace；重复打开同一文件夹仍新建 workspace。
- 当前查看 SSH 会话时，文件夹请求使用本地连接。
- 开发版服务名称为 `Open New Workspace in Water Dev`，与正式版区分。

服务显示取决于 macOS 服务注册、缓存和启用状态。Finder 实际菜单点击、应用冷启动投递和多 GUI 进程下的目标窗口选择尚未验证。

新增目录及重复创建回归测试通过；unit profile 的 harness、vet、普通测试和 race 全部通过。本机签名的 macOS arm64 包通过签名与 ZIP 校验，实际打包应用通过 GUI pane 冒烟验证及自有实例清理。Linux 原生运行未验证。
