# Water 0.4.10

Pane closing restores the most recently focused surviving pane, pane sizes have configurable shortcuts, and macOS foreground process sampling uses native kernel queries.

- Pane divider hover guides stay hidden while the Water window is unfocused. Scrolling an unfocused window continues to work.
- Closing a pane returns focus to the previously focused surviving pane in the same tab, independently for each window.
- The final pane can close its tab, including the final tab in a workspace.
- Settings → Shortcuts → Panes adds Cmd+Shift+H/L to narrow/widen by one terminal column and Cmd+Shift+J/K to shorten/grow by one terminal row. Holding a key repeats the adjustment; nested layouts use the nearest split with the matching axis.
- The remote connection shortcut defaults to Cmd+Alt+K to avoid the new pane-height shortcut. Legacy default configurations migrate automatically.
- macOS Agent recognition samples PID, foreground process group, precise start identity and complete arguments directly from the kernel. Agent controls still recheck the foreground run before signaling it.
- The terminal throughput gate compares direct and server streams under simultaneous load while retaining the 60% retention requirement and bounded-queue/sequence checks.
