# Water 0.3.7

减少空闲终端的 server 内存占用，增加光标外观设置，并修复 macOS Retina 下输入法候选框的定位坐标。

- PTY 读取缓冲区按需分配，每个终端只缓存少量空闲块。四个空闲 PTY 的受控测试中，保留 Go heap 从约 32 MiB 降至约 1 MiB；回放容量、背压和 Output → Resize → Exit 顺序保持不变。
- Settings → Terminal 支持块、竖线、下划线，以及独立的闪烁开关；六种组合均可保存并立即生效。终端应用仍可通过 DECSCUSR 覆盖光标，CSI 0 SP q 恢复用户设置。
- 修正 macOS IME 的 backing pixels 与 AppKit points 转换；空闲输入会话随光标位置和布局变化刷新。正在输入的组合文本保持完整，位置刷新延后至组合结束。
- `water ctl debug memory` 增加 Go heap 已分配、使用中、空闲和已释放字节数，便于区分必要回放、活跃数据与运行时保留内存。

全仓 Go 测试、go vet、相关 race 测试及四组 scenario 通过。真实 Retina GUI 验证六种光标组合、设置持久化和 IME 坐标跟随；完整 Settings/键盘 GUI 回归通过。小企鹅候选框的实际输入验收尚未直接观察。

macOS arm64 安装包通过本地原生构建和 signing-only workflow 发布。测量方法及验证边界见 [修复报告](https://github.com/SurTeam/Water/blob/v0.3.7/docs/server-memory-cursor-ime-2026-10-05.md)。
