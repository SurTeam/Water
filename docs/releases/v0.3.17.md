# Water 0.3.17

改善文本选择、窗口内弹窗和侧边栏点击反馈，并降低终端高吞吐输出时的空读开销。

- 拖选以字符格中线确定选区边界，正反向拖选保持一致；高亮和复制仍覆盖完整宽字符。
- 修复 Shift＋点击扩选：保留现有锚点并更新另一端，支持跨过锚点反向选择；双击选词不会再被鼠标松开的位置覆盖。
- 远程连接和其他共用输入框按字体度量垂直居中；窗口内弹窗统一移除阴影，保留背景压暗且不重复叠加遮罩。
- Workspace 普通点击不显示拖动指示器，移动超过 5dp 后才启用拖动提示。
- PTY 在暂时无数据时使用带期限的内核就绪等待，保留部分读取块，避免连续空读；队列/replay 上限和 Output → Resize → Exit 顺序不变。
- `water ctl ui click` 支持 `--shift`，新增选择、扩选、弹窗像素及稀疏输出回归，并将选择/弹窗 GUI 检查纳入 regression profiles。

本机 macOS arm64 单次 64 MB 服务端基准中，PTY 读取调用从 549,494 降至 135,630（约减少 75%），吞吐从 83.44 MB/s 到 85.71 MB/s。性能门禁单项测量的 server/direct 保留率为 95.5%，Resize 约 1.53 ms，Ctrl-C 到退出约 0.69 ms。绝对吞吐受机器负载影响，这些数字不是统计估计；门禁阈值没有放宽。

验证：完整 unit profile（go vet、全仓 Go 测试、race）通过；四个既有 scenario 和真实原生 GUI smoke 通过；真实 GUI 选择、Shift 扩选、双击选词、远程输入框居中及弹窗无阴影检查通过。测试使用独立配置、socket 和自有进程，保留用户已有 Water 实例。正式 macOS arm64 包在本机使用发布证书签名，验证 updater/server/GUI/app 的严格签名、签名时间戳、版本和变体一致性及 ZIP 完整性；包内 release GUI 的选择/弹窗和 Settings 视觉检查通过。
