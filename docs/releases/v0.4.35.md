# Water 0.4.35

修复关闭窗格后，前台或后台程序仍可能继续运行的问题。

- 进程内终端与新版 PTY supervisor 共用强制清理逻辑，在终止 shell 前识别同一终端会话中的程序及仍可追溯的派生进程，以 `SIGKILL` 结束程序，覆盖独立任务组和仍可追溯的另建会话子进程。
- 清理前校验进程启动身份，避免已回收或复用的 PID 触发无关会话的清理；进程枚举有界，失败时保留安全回退。
- 清理为尽力执行，已经脱离会话且失去可追溯关系的进程不保证被终止。升级后仍保留的旧 supervisor 继续使用原有清理逻辑；仅更新 GUI 或通过 recovery 接回已有 PTY 不会替换其代码。

已完成 unit profile（测试工具自检、Go 单测、vet、race）。最后的根进程身份保护调整另经受影响包的定向单测、race 和 vet，覆盖忽略信号、独立进程组、跨会话后代、相邻终端隔离、枚举失败回退及历史 PID 安全检查。本次版本递增不重复运行整套测试。测试运行于 macOS；Linux 运行行为未实测。

发布 macOS arm64 安装包，使用本机 SurTeam 证书签名。
