# Water v0.4.43

## macOS 本地更新进程交接

- 新启动的更新 helper、本地 server 和 PTY supervisor 在建立独立 session 的同时，解除与启动应用的 macOS process responsibility 关联，修复仅使用 `setsid` 仍保留应用归属的缺口。
- 交接保留进程 PID 和更新握手管道；内部启动标记在初始化时消费，无法解除归属时明确启动失败。
- PTY 鼠标恢复测试按字节内容比较 `od` 输出，兼容不同平台的填充空格。

## 更新与验证边界

更新使用当前已安装包的 helper；已经运行的旧 server、supervisor 和 helper 不会因为安装新版本而自动解除原应用归属。因此从旧版本首次升级到本版本仍不能保证取得此保护；需要在本版本启动这些进程后，再验证后续应用更新的会话保留。

按用户要求，本次提交和发布阶段不再运行测试。实现阶段已通过平台进程归属、PID 与继承管道检查、更新器测试、PTY 跨 server 重启测试、vet 和相关 race 检查；尚未完成真实安装包的完整更新回归，由用户验收。发布包含 macOS、Windows、Linux 的 amd64/arm64 构建，执行平台签名、归档完整性和上传资产摘要核对，不代表异平台原生运行验证。
