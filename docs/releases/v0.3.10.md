# Water 0.3.10

修复 macOS Retina 屏幕上输入法候选框位置偏移的问题。

- 移除 IME 光标坐标的重复缩放：Ebitengine 已将逻辑坐标转换为 AppKit 点，Water 直接传入与终端和编辑器绘制一致的逻辑坐标。
- 修正坐标回归测试和真实 GUI 验证脚本，避免再次把缩小一半的候选框锚点视为正确结果。

问题由小企鹅输入法截图确认。坐标回归测试、go vet 和 Retina 真实 GUI 验证通过，两处终端光标位置的 IME 锚点均正确跟随；尚未完成修复版的小企鹅物理输入及候选框目视验收。

macOS arm64 安装包使用本地原生构建，并通过 signing-only workflow 签名和正式发布。
