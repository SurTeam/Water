# Water 0.4.25

区分后台 server 与 PTY supervisor 进程，并改善终端输出刷新和重复绘制开销。

- macOS/Linux 本地包的 PTY supervisor 使用 `water-pty`（release）或 `water-pty-dev`（dev）；主 server 保持 `water-server` / `water-srv-dev`。旧包及远端 payload 保留原名称回退。
- supervisor 仍持有 PTY，使终端程序跨 server 重启存活；已运行的旧 supervisor 会继续使用原名称，直到它退出并由新构建重新启动。
- 可见终端持续输出发布频率由约 30 Hz 提高到约 60 Hz，首批输出仍立即发布；输入命令减少无关的工作区快照广播。
- 快照发布等待解析时不再持有 view 锁；未变化的终端行复用纹理与排版缓存，macOS 可见性与按键重复检查减少重复工作。

验证范围为相关 Go 包测试、本机 macOS arm64 签名构建与 archive 验证；Linux 原生包和远端升级未在本次发布运行验证，不宣称整体 CPU 或能耗的量化改善。
