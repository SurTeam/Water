# Water v0.4.52

## 更新后自动恢复 Downloads / FDA 权限

应用内更新会保活本地 server。macOS 原地替换 `water-pty` 后，旧 supervisor 仍占着已有 PTY，但 TCC 按新路径签名检查，新 shell 会丢失完全磁盘访问（含 Downloads）。

替换 GUI 在首帧 ACK 释放保活后，若本地 server 仍是更新前的 revision，会自动 recovery 重启并接上当前 supervisor；保活期间新建 shell 前也会再跑一次世代检查。已有 shell 不会因此恢复权限；远端连接仍走原有过期提示。

## 验证与发布状态

`goui`、`goserver`、`goplatform` 相关单元测试与 `go vet` 通过。现场恢复重启后，新 shell 可列出 Downloads。未跑完整 GUI regression profile；异平台产物仅交叉编译打包，不另做运行时验收。
