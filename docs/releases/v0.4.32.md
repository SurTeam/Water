# Water 0.4.32

修复 macOS 终端 Cmd+V 对富剪贴板的粘贴选择：

- Excel 等同时提供文本和图片的内容默认粘贴纯文本，保留 Tab 和换行，避免被误当成图片而没有文本输入。
- 图片附带绝对文件路径或 `file://` URL 时仍优先图片粘贴；纯图片继续通过 Ctrl+V 交给支持系统剪贴板的应用读取。
- PDF 等非图片文件及混合文件引用继续粘贴 shell 引用的路径文本。

图片粘贴依赖接收应用读取系统剪贴板，不会自动向远端上传图片。图片路径识别依据扩展名，不解码源文件。

本次提供 macOS arm64 安装包，使用本机 SurTeam 发布证书签名；app 严格签名验证、ZIP 完整性检查及隔离实例中的 0.4.32/release 身份、启动和 shell 输出验证通过，原有 Water 进程保持运行。

验证覆盖全仓单元测试、vet、相关包 race、终端场景及 terminal profile 的全部检查项。整套执行在文本粘贴的 ZLE 校验中出现一次超时，随后同一构建的该项独立复验通过，剩余检查项逐项完成。原生混合剪贴板另行验证了表格文本优先、带文本路径和文件 URL 的图片优先、PDF 路径及纯图片分支；夹具保存并恢复原剪贴板。Linux 原生运行、真实物理按键及具体 TUI 对原图内容的读取未验证。
