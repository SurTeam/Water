# Water 0.4.27

配置目录统一使用 XDG 路径，并在设置中提供可发现的配置文件入口。

- 正式版默认 `~/.config/water/config.json`，开发版使用 `water-dev`；优先 `$XDG_CONFIG_HOME`，兼容 `$XDG_CONFIG`，只采用绝对路径。
- macOS 首次读取新路径时安全复制旧 Application Support 配置，保留原件，不覆盖已存在的新配置。
- 设置顶部显示实际配置路径，可一键打开配置文件夹；恢复默认先预览，保存后生效。
- 统一 GUI、TUI、控制命令与 server 的 `--config`、`WATER_CONFIG` 和默认路径优先级。

升级后请重新启动 GUI/server，让新进程使用统一路径；旧进程仍可能保存到旧文件。旧文件不会持续同步，回退旧版本时需自行同步后续更改。其他旧目录数据保持原处，Web 授权可能需要重新配对。自定义配置目录的文件系统需支持硬链接以执行首次迁移。

配置路径及迁移测试、Go 普通测试、vet 和真实 GUI 设置保存、恢复默认、目录入口验证通过。完整 unit 流程的 race 阶段有一个 Agent 进程采样测试在三秒等待内未完成分类，其余 race 包通过。本次发布本机签名的 macOS arm64 包；Linux 原生运行未验证。
