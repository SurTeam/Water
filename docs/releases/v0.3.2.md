# Water 0.3.2

本补丁优化 GUI 内存和持续输出时的输入、绘制节奏，并修复 macOS 后台启动问题。

- 字体按实际需要加载，压缩字体集合的内存投影，按需解码并限制字形缓存；减少终端和圆角绘制的 GPU 内存。
- 可见画面按行复用不可变数据，由绘制消费驱动更新，移除独立的整屏快照定时器。后台保持 PTY 事件顺序，隐藏窗口暂停制作画面。
- 活动窗口跟随显示刷新节奏；解析与画面读取分离，输入不再等待解析锁。控制键重复使用实际时间，避免积压后成批重复。
- 修复遗留 daemon 环境标记进入子进程时，Water Dev 图标持续跳动而窗口无法打开的问题。

在本机连续输出 1 MiB/s、20 秒的测试中，GUI RSS 为 297–303 MiB，物理 footprint 为 352–358 MiB；因此 300 MB 是优化目标，并非所有配置下的硬上限。4 MiB/s 输出测试中，Update P99 为 0.692 ms。50 Hz 控制 API 输入测试的往返 P99 为 10.20 ms；这些数据不替代物理键盘和 IME 的体验验收。

完整 Go 测试、go vet、相关并发测试及真实 GUI 设置、字体、尺寸、隐藏恢复和冷启动检查已通过。详细方法与限制见 [性能验证报告](../memory-input-profile-2026-10-04.md)。

macOS arm64 安装包通过签名工作流验证后发布。开发版与正式版继续使用独立的配置、socket、进程和 Bundle ID。
