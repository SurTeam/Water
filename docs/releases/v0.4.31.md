# Water 0.4.31

维护发布，递增补丁版本并重新打包。应用源码行为与 0.4.30 一致，继续包含中文工作目录查询和新建终端失败回滚修复。

已保存的恢复文件独立于应用安装包；升级不会自动修正旧文件中已经保存的错误目录。遇到恢复失败时，应先检查恢复文件中的工作目录，备份后再修正，并通过 Server 设置中的 Retry restore 重试。

本次提供 macOS arm64 安装包，使用本机发布证书签名，app 签名和 ZIP 完整性检查通过。签名安装包在隔离 GUI 实例中通过启动、版本身份与真实 shell 输出验证，测试清理确认原有 Water 进程保持运行。发布前同一应用源码的完整 unit profile（harness、vet、全量 Go 测试及相关包 race）通过；Linux 原生运行及完整 terminal profile 未验证。
