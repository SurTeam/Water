# Water 0.4.6

降低字体加载时的常驻内存，并释放图形解析器用完后仍占着的缓冲。

- 静态 `glyf` 字体在加载时只检查 loca 偏移，不再逐个读取字形头。度量按需读 10 字节头，轮廓仍按需解析。空字形不会读到下一个字形；短于 10 字节的记录仍会拒绝该字体。带 `gvar` 的可变字体继续整表解析。
- 图形协议解析结束后，空缓冲若容量超过 4096 字节即释放。仍有未完成数据、且空闲至少 1 MiB 并且容量至少是长度两倍时，只保留还活着的字节。
- macOS 标题栏和侧栏拖动改由 AppKit 跟踪，窗口跟随光标，不再等帧循环。窗口重新可见后短暂关闭垂直同步，并把补绘摊开，避免激活时转圈。
- 粗体字体选择、回滚行数和重连历史上限不变。已绘制的字形仍会按页调入。

验证：`go test -C third_party/typesetting ./font/` 与 `go test -race` 通过；`go test ./internal/govt/ -run GraphicsParser` 通过。
