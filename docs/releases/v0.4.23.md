# Water 0.4.23

优化 supervisor、server replay 与 GUI 的 ANSI 输出管线，减少高吞吐终端的 CPU 和分配开销；同时包含前台 Agent 检测与采样可靠性修复。

## 终端吞吐

- supervisor 在 reader 内将内核碎片聚合进 128 KiB 块，减少逐碎片分配与调度；保留空闲刷出期限及有界备用块复用。
- supervisor 的 2 MiB 原始历史改为环形缓冲，避免满历史后每批输出搬移整段数据；attach 按绝对 offset 复制有序历史。
- server replay 将普通 ANSI 转义和相邻文本按连续原始字节段存储，减少逐转义的重复扫描、计数和追加，保留主副屏切换与不完整序列边界。
- GUI 对 ANSI 中的普通 ASCII 文本批量写入 cells，保留属性、宽字符清理、换行和滚动语义；特殊模式与非 ASCII 使用通用路径。

## Agent 检测

- 修复前台进程组检测与采样的可靠性，避免 supervisor 查询和并发响应影响 Agent 状态识别。

## 验证与测量边界

- terminal profile、相关单元测试与 race 检查通过，覆盖历史、图形、粘贴、Pi 重绘、重接及 Metal readback。
- 本机隔离 GUI 中，61.4 MB 原始 ANSI 测试的三次 real 为 0.717 / 0.705 / 0.693 秒，修改前为 1.368 / 1.343 / 1.418 秒。该结果是指定负载的本机测量，不是跨机器延迟保证。
- 提交前后分别连续处理同一文件 40 次、共 2.456 GB：三个 Water 进程合计 CPU 时间约从 179 秒降至 109 秒，GUI 累计分配约从 7.915 GB 降至 3.732 GB，RSS 峰值接近。新版本负载后段 RSS 趋稳，停止输出后 CPU 回落；20 秒恢复期内 GUI RSS 未像旧版一样明显回落，短时测试不证明长期无泄漏。
- 持续输出期间验证 GUI 输出进展及控制注入响应；物理键盘、IME 与硬件上屏延迟不属于该测量。

发行产物为本机原生 macOS arm64 签名包；交叉编译的内嵌 server payload 不代表其他平台原生运行验证。
