# Water 0.4.7

water-server 的重放历史改按滚动行数保留，不再为每个终端囤积用不到的屏幕重绘。

- 主屏幕重放保留配置的滚动行数，再加当前一屏。普通文本行按换行保留，不会被截断。
- TUI 备用屏幕的重绘单独存放，并且限制在一屏以内。这些字节不计入滚动历史，也不会把进入 TUI 之前的 shell 历史挤掉。离开备用屏幕后，重放回到主屏幕历史。
- 主屏幕上超长的转义重绘只保留一屏；这段前后的历史行仍然保留。
- 设置中移除「重连历史容量」和「历史内存上限」。旧配置里的这两个字段会被忽略。滚动行数仍是唯一的历史控制。
- 长时间运行的 shell 只在前台状态真正变化，并且上一条命令已经超过阈值时才通知。隐藏终端的输出不再带动可见窗口重绘，突发的终端写入会合并，不会把会话队列写满后关掉。

验证：40 个真实 PTY 同时保留历史，其中 20 个 TUI 退出备用屏幕、10 个停留在备用屏幕、10 个只在主屏幕重绘。原始输出约 57.6MB，留存重放 1,272,920 字节；退出备用屏幕后不保留 FRAME 重绘，进入前的 shell 行仍在。`go test ./internal/goterminal/ ./internal/goconfig/ ./internal/goserver/ ./internal/goui/` 通过。
