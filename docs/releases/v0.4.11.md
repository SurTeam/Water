# Water 0.4.11

Agent recognition rules now have a guided editor with current-pane process autofill, and SSH servers respect the remote user's default shell.

- Default shell selection respects the current user's `SHELL`, including the remote account when a server starts through SSH. Explicit `shell.program` configuration and `WATER_SHELL` overrides remain higher priority.
- Settings → Agents replaces raw JSON rule editing with a guided popup. Each condition explains its field, matching operator and value; rules and conditions can be added, removed and reviewed before applying.
- **Fill from current pane** reads the focused terminal's foreground process and fills executable-name and per-argument exact conditions. All programs use the same mapping, without interpreter-specific inference. Only the selected rule changes; other rules remain intact.
- Autofill remains an unsaved draft until applied. Canceling, failed sampling, changing the focused pane and late replies cannot overwrite the draft. Samples beyond the existing condition/value limits report an error without truncating the process data.
- Rule values remain literal matching data, with standard JSON serialization handling quotes and backslashes. No rule value is evaluated as a shell command.
