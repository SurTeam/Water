# Water v0.4.41

## GUI 输入延迟与字段光标

- macOS 上字段聚焦时 IME 视图先于 GLFW 键采样消费编辑键（Backspace、方向键等），应用这些文本命令后没有触发帧刷新：backspace 后旧文字保留在屏幕上，直到输入下一个字符；光标移动同样滞后。现在文本命令队列非空时应用后立即触发一次帧失效（空队列不触发），本地编辑当帧呈现。修复覆盖全部共享输入路径：远程连接表单、Settings 行、rename 与 Agent rules 字段。
- 输入字段光标与终端光标保持一致：形状跟随 `cursor_style` 设置（block 反转覆盖字符、bar、underline），使用同一主题颜色（`cursor_background`/`cursor_foreground`）；闪烁跟随 `cursor_blink` 并与终端光标共享同一相位，空闲窗口在相位边界为聚焦字段唤醒帧调度。

## 验证与发布状态

修复已通过完整 `go test ./...`、`go vet ./...`、相关包 race 检查与 `terminal` 回归 profile（scenarios 与 GUI smokes）。新增单测覆盖 IME 编辑键应用后的帧失效（含空队列不触发）与字段光标闪烁调度路径；`go-ui-selection-modal-smoke` 校验字段光标与文字的垂直居中。

发布包覆盖 macOS、Windows、Linux 的 amd64/arm64，全部在 macOS 主机完成构建。Linux 使用 Zig 与 Alpine 3.22 动态 musl sysroot 交叉编译，不依赖 glibc；运行时使用目标系统的 musl、X11 和 Mesa EGL/GL 库。不启动 Colima、容器或虚拟机。只验证当前主机对应的 macOS arm64 版本，其他目标不要求异平台验证。macOS 和 Windows 使用平台代码签名，并提供签名的 SHA256SUMS；交叉构建不等于原生桌面运行验证。签名不代表 Apple 公证、系统预装证书信任或 SmartScreen 信誉。

发布时按[构建与发布](../build-and-release.md)完成当前主机验证，并逐项核对 GitHub API 的资产 SHA256 digest、大小及完整文件名集合；核对通过后才公开 release，不重新下载发布资产计算哈希。
