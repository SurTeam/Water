# Water 0.4.36

缩短后台终端快照占用 GUI 视图锁的时间，减少输入响应与 pane 切换被快照构建阻塞的机会。

- 后台构建不可变快照时释放视图锁，绘制与 pane 命中测试可以继续读取上一帧；解析/生命周期锁仍覆盖构建与发布，保持终端生命周期和视口操作顺序。
- 发布新快照不覆盖构建期间到达的新输入及选区更新。
- 终端纹理样式缓存改为完整值比较，去掉每次绘制时将整套颜色主题格式化为字符串的开销。

沿用修复阶段的验证结果，本次版本递增与发布不重跑测试。此前完整 Go 单测、vet、race、基础 GUI 冒烟和定向并发回归通过；独立 GUI 的 pane 操作及持续大输出下另一 pane 输入通过功能检查。完整 terminal profile 因测试生命周期清理失败未通过，未执行其全部后续项目，不宣称整套回归成功。现场只读采样未捕获用户报告的长时间输入停顿，因此不能确认该锁竞争是所有卡顿的唯一原因。

发布本机 SurTeam 证书签名的 macOS arm64 安装包。运行中的 GUI 需要更新并重新打开才会应用修复；同步恢复/几何/样式快照及繁忙 pane 交互的既有限制仍保留。
