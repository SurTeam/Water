# Water 0.4.21

新增 `water ctl pane execute` 与 `pane.execute` RPC，Agent 可在指定 pane 执行命令，一次获得退出状态和本次范围内的终端屏幕文本。服务端通过 `pane-execute/v1` capability 声明支持；旧的常驻 server 不会自动重启。

- 在正常范围有效时使用执行生命周期标记隔离输入回显和之前的输出；范围失效的屏幕回退可能包含周围旧内容，支持有界行数/字节数，并报告截断与备用屏幕。
- 超时校验执行进程身份后先 TERM，再于 250ms 宽限期后 KILL，保护 pane shell；清理覆盖同一进程组内忽略 TERM 的后代。
- 命令在子 `/bin/sh` 中运行，不持久化目录与变量变化；非零退出、超时和执行失败分别可检查。详见 [控制 API](../control-api.md#在指定-pane-执行命令)。
- 同步控制 API、终端/服务边界和随 macOS app 分发的 water-control skill。

真实 PTY/RPC 回归覆盖屏幕范围、ANSI 重绘、非零退出、长命令与控制字符、超时升级、后代清理和 shell 存活。发行产物范围为本机原生 macOS 架构；交叉编译的 server payload 不代表其他平台原生运行验证。
