# Water v0.4.51

## 普通大粘贴不再被 cooked PTY 截断

Darwin 等 Unix 的 cooked/ICANON 输入受 `MAX_CANON`/`MAX_INPUT`（1024）限制。未启用 bracketed paste 时，一次粘贴超过该上限会被 `cat` 等程序丢掉。

GUI 与 TUI 现在把普通大粘贴放进 FIFO pending 队列，按换行优先切成不超过 512 字节的块，块间留短间隔让读者排空；仍以 `\x1b[200~` 开头的 bracketed paste 继续走大块会话写入。会话背压继续重试 pending，而不是永久停输入。

## 验证与发布状态

`goui`、`gotui` 相关单元测试通过。隔离 GUI smoke 的 cooked 阶段确认约 3 KiB 普通粘贴完整送达；raw 大粘贴与 bracketed 路径仍通过。未跑完整 GUI regression profile；异平台产物仅交叉编译打包，不另做运行时验收。
