# Water v0.4.44

## GUI 与服务端生命周期解耦

- GUI 始终启动或连接打包的独立本地 server，不再按 `server.detached` 在 GUI 进程内运行 server。关闭单个或最后一个窗口只释放对应 session；workspace、PTY、supervisor 与 Web listener 继续运行，重新启动 GUI 会接回同一 server 实例和模型。
- 普通退出、启动失败清理和更新期间的 GUI 会话都不再请求 `shutdown_if_last`；显式 Quit GUI and Local Server 和 server 重启仍会停止本地服务。
- `server.detached` 与 `server.detach_on_quit` 保留为旧配置读取兼容字段，不再出现在 Settings，保存时清除，且不再影响生命周期。
- 服务端写入会话帧增加 5 秒 deadline；写入失败或超时关闭连接，避免部分帧后复用连接。`session.open` 只把 admission 放在全局命令锁内，回复和快照写入移到锁外，单个停滞的 GUI 不再冻结其他命令。

## 验证与发布状态

单元回归覆盖独立 server 在 GUI session 重启后保持 PID、实例和模型，更新清理保留 server 与 PTY，旧配置启动独立 server，服务端阻塞握手不持有全局命令锁，以及停滞写入超时关闭连接。相关 `goconfig`、`goui`、`gouiapp`、`goserver` 测试与 `go vet` 通过；macOS 原生 GUI 生命周期与多窗口检查按[测试策略](../testing.md)执行，结果以实际发布记录为准。

发布包含 macOS、Windows、Linux 的 amd64/arm64 构建，全部在 macOS 主机完成。Linux 使用 Zig 与 Alpine 3.22 动态 musl sysroot 交叉编译，不依赖 glibc；不启动 Colima、容器或虚拟机。只验证当前主机对应的 macOS arm64 版本，其他目标只构建、打包和签名，不代表异平台原生运行验证。macOS 和 Windows 使用平台代码签名，并提供签名的 SHA256SUMS；签名不代表 Apple 公证、系统预装证书信任或 SmartScreen 信誉。
