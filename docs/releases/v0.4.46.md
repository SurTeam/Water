# Water v0.4.46

## 自定义 Agent 识别 FirstRule 的 OSC 7501 结束状态

- 侧栏采纳 OSC 7501 程序状态时，自定义 Agent profile 的 kind 是 UUID，原先只按 `app == kind` 匹配，导致 FirstRule 上报的 `app=firstrule` 状态（含结束 `done`）被丢弃。现在默认匹配分支在 `app == kind` 之外，接受规范化后的 profile 名包含规范化 app 身份的报告（如名为 `FirstRule Go` 的 profile 采纳 `app=firstrule`），turn 结束后侧栏正确显示 Completed 指示。
- 内置 Agent 仍按固定 app 身份匹配，不受 profile 名影响；识别继续由 config.json 的自定义 Agent profile 承担，未新增内置规则。

## 验证与发布状态

新增自定义 profile 的 app 身份匹配单元测试，以及端到端测试验证自定义 profile（UUID kind、名 FirstRule Go）收到 `app=firstrule` 的 working/done 报告后侧栏状态变 Running → Completed。`go build`、`go vet` 与 `internal/goui` 全量测试通过。

本次发布构建当前主机 macOS arm64 的 release 版本；未交叉编译其他平台，未启动 Colima、容器或虚拟机。

release 版本以 SurTeam 证书正式签名（`CODESIGN_IDENTITY` 为 SurTeamCode、`CODESIGN_REQUIRED=1`），`codesign --verify --deep --strict` 通过且 bundle satisfies its Designated Requirement；未签名或 ad-hoc bundle 不能作为自动升级的安装包。发布指将该已签名 zip 上传到 GitHub 创建对应 release（非 draft、非 prerelease 的 `v0.4.46`，资产名 `Water-0.4.46-macOS-arm64.zip`）。
