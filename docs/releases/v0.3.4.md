# Water 0.3.4

本补丁减少高速持续输出时重复生成画面、文字对象和窗口更新的开销。

- 客户端完整按序解析终端输出；第一次变化立即发布，持续输出最多约 30 次/秒呈现最新完整画面，跳过中间画面。
- 纯输出通知与输入活动分开，持续输出不再反复启用显示器刷新率的输入循环；键盘、鼠标、滚动、拖拽和 IME 保留各自的交互路径。
- 文字 run 使用线性增长的字符串构建，减少逐字符复制前缀；字体、连字、宽字符和颜色分组规则保持一致。
- 诊断构建提供阶段耗时、解析字节数、重绘行数及 Invalidate 调用栈计数；测量脚本等待输出程序真正启动，记录可见性和实际解析速率。

同机普通构建短窗口中，1 MiB/s ANSI 目标负载的 CPU 为 38.9% → 20.0%，4 MiB/s 为 60.2% → 26.8%。修改版较长连续输出窗口为 32%–36%，**高速输出 10% 的目标尚未达到**。30 次/秒是持续输出呈现的明确取舍，回显也可能等待下一份快照；吞吐、字体、窗口尺寸、桌面交互和遮挡会影响结果。

Go 全量测试、go vet、相关 race 测试、诊断构建测试及四组 scenario 通过。真实 GUI 输入和 PTY 查询检查完成：修改版后续五轮各 36 个查询均通过，但最初一次 CSI 19t 回复超时未确定原因，保留为验证限制。方法、原始证据及后续重写方向见 [CPU 管线报告](../cpu-pipeline-profile-2026-10-04.md)。

macOS arm64 安装包使用本地原生构建及 signing-only workflow，签名验证通过后发布；本次不替换正在运行的用户 Water.app。
