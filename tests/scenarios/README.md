Scenario fixtures are executed by `water ctl scenario run` in `cmd/water/ctl.go`. Workspace-creation fixtures expect a clean model; start the server or GUI with `--empty-workspace` when running them through `water ctl`. `scripts/run-go-scenario-suite.sh` runs each fixture against its own server.

Every command step is dispatched through the versioned control socket and server command path, then awaited by operation ID. Terminal fixtures may use `terminal_contains` and `process_exit`, which perform bounded waits over terminal state. `terminal_zsh.json` exercises an interactive explicit `/opt/homebrew/bin/zsh -f` fixture when that Homebrew installation is available; default Water terminals use the configured login shell. Do not add fixed sleeps or coordinate-based UI assertions here.
